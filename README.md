# Sujin S — Cloud & DevOps Portfolio

A responsive, single-page portfolio for Sujin S, built with plain HTML and CSS for GitHub Pages. Its dark visual style follows the supplied design reference: Chakra Petch headings, Manrope body text, charcoal panels, lime accents, warm peach gradients, and outlined technology icons. The portfolio content follows [sujinsj13.github.io/website](https://sujinsj13.github.io/website/) and the approved concise experience summary.

## Files

- `index.html` — page structure, portfolio content, and navigation
- `styles.css` — colors, layout, responsive breakpoints, and accessibility states

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.

## Publish with GitHub Pages

1. Commit `index.html` and `styles.css` to the repository's deployment branch.
2. In the repository's **Settings → Pages**, select the branch and the repository root as the publishing source.
3. Save the setting and open the Pages URL after the deployment completes.

The page has no build step or JavaScript dependency. Fonts load from Google Fonts with system sans-serif fallbacks. The decorative technology icons are inline SVG, so no image assets or icon libraries are required. Responsive layouts and reduced-motion preferences are supported.
