# Sujin S — DevOps Portfolio

A responsive static portfolio website built with plain HTML, CSS and JavaScript.

## Deploy with GitHub Pages

1. Create a new GitHub repository, for example `devops-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the live website URL.

## Customize

Update the email, LinkedIn, GitHub URL, experience, projects and skills in `index.html`.
